# Real-Time E-Commerce Data Ingestion Pipeline

This project contains a complete data ingestion and processing pipeline using Python and Apache NiFi. It simulates real-time, semi-structured e-commerce transactions, processes the messy data to enforce quality rules, and outputs clean data.

## Repository Structure

* **`simulate_stream.py`**: A Python data simulator that uses the `Faker` library to generate batches of e-commerce records. To simulate real-world data issues, it intentionally injects anomalies into the stream, including a 10% chance of missing prices, a 10% chance of integer-based Unix timestamps, a 10% chance of missing product names, and a 5% chance of duplicate records. It writes these batches to a local directory as newline-delimited JSON (NDJSON).
* **`nifi_flow/`**: Contains the pipeline architecture.
* `nifi_flow_templete_nifi_2.9.0.json`: The exported Apache NiFi 2.9.0 template. The flow is modularized into dedicated Process Groups: File Ingestion, Data Transformation, DB Ingestion, and Enrichment.


* **`sample_data/`**: Contains examples of the data before and after passing through the NiFi transformations.
* `transactions_batch_20260511135716.json`: A sample of the raw, unformatted data generated by the Python script, showing raw timestamps with microsecond precision and duplicate entries.
* `sample_processed_data.json`: The final, cleaned output data. This file demonstrates the successful application of the NiFi pipeline, showing standardized `yyyy-MM-dd HH:mm:ss` timestamps and the removal of malformed or duplicate records.
